# Ai GROW 成長バッジ｜デザイントークン仕様

**バージョン** 1.0.0 ／ **確定日** 2026-08-31
**配色方針** 獲得済み＝淡色案 × 未獲得＝ロック候補A

---

## 1. 基本方針

- ロック状態でもレア度の色相を残し、彩度だけを落とす。グレー1色に統一しない
- グリフは単色。色はVariableで注入し、アセット側に色を持たせない
- 未獲得用のアセットは作らない。`state` プロパティで生成する
- 色はレア度の補助的な手がかりであり、唯一の識別子にしない（チップ表記とラベルで冗長に伝える）

## 2. カラートークン

### 2-1. 獲得済み（earned）

| Tier | タイル地 | タイル枠線 | グリフ | チップ地 | チップ文字 | ラベル |
|---|---|---|---|---|---|---|
| N | `#F2F3F5` | `#E3E5E9` | `#2A2F37` | `#9AA1AC` | `#FFFFFF` | `#1A1A2E` |
| R | `#EDF1FE` | `#4C6EF5` | `#3B5BDB` | `#3B5BDB` | `#FFFFFF` | `#1A1A2E` |
| SR | `#F4EFFE` | `#8B6FE8` | `#7C5CE0` | `#7C5CE0` | `#FFFFFF` | `#1A1A2E` |
| UR | `#FDF6E6` | `#E8B33C` | `#D99A1F` | `#D99A1F` | `#FFFFFF` | `#1A1A2E` |

> **N のグリフのみ例外的に濃色。** 他Tierはタイル地と同系色だが、Nはグレー同士で明度差が出ないため `#2A2F37`（ほぼ黒）を当てている。N獲得済みは全35枠中12枠を占めるため、ここが弱いとグリッド全体が沈む。

|---|---|---|---|---|---|---|
| N | `#F7F8F8` | `#EBECEE` | `#C9CDD3` | `#DCDEE2` | `#6E757F` | `#A8ADB5` |

## 3. ジオメトリ

| 要素 | 値 |
|---|---|
| タイル | 96 × 96 px ／ 角丸 20px ／ 枠線 1px |
| タイル（UR のみ） | 枠線 **1.5px** |
| グリフ | **72 × 72 px** ／ 中央配置 |
| 錠アイコン（未獲得時） | **40 × 40 px** ／ ストローク 2px |
| レア度チップ | 直径 28px ／ タイル右上（右 +8px / 上 −8px） |
| チップ文字 | 11px / Bold |
| ラベル | タイル下 8px ／ 13px / Bold ／ 中央揃え |
| ソリッドシャドウ（獲得済みのみ） | offset (4px, 4px) ／ ぼかし 0 |
| ソリッドシャドウ（未獲得） | **なし** |
| カード | 角丸 16px ／ 内側 padding 20px ／ 4カラムグリッド |

### 錠アイコンをグリフより小さくする理由
グリフと同じ72pxにすると南京錠が主役になり、「まだ取れていない状態」ではなく「錠前という絵柄のバッジ」に見える。獲得済みは絵柄として大きく、未獲得は状態表示として小さく扱う。結果として獲得／未獲得の差も強まる。

### グリフを72pxで止めている理由
タイル96pxに対し上下左右12pxの余白。80pxまで広げると `broaden` の右上方向の矢印や `season-cycle` の外周がレア度チップに接触する。さらに詰める場合はチップの位置またはサイズの調整が必要。

## 4. グリフアセット規格

| 項目 | 値 |
|---|---|
| viewBox | `0 0 24 24` |
| 表現 | ベタ塗りシルエット（**内側余白 0**・最長辺を24pxにフィット） |
| 色指定 | `fill="currentColor"` |
| ストローク | 使用しない |
| 抜き表現 | **`<mask>` による真の透過**（背景色パスでの塗り潰しは不可） |
| 最小要素幅 | 3px 以上 |
| 禁止 | 文字・数字・グラデーション・影・固定色 |

### mask 方式が必須である理由
画像トレース出力は、穴の部分を透明ではなく背景色のパスで塗り潰す。この状態で単色を注入すると全体がベタ塗りの塊になる。また UR のグラデーションタイル上では、塗り潰し部分が平坦なパッチとして露出する。マスクで真の透過にすることで、両方を回避する。

```svg
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24" width="24" height="24">
  <mask id="g_example" maskUnits="userSpaceOnUse" x="0" y="0" width="24" height="24">
    <g transform="translate(tx ty) scale(s)">
      <path d="…" fill="#fff"/>  <!-- 図：塗る部分 -->
      <path d="…" fill="#000"/>  <!-- 地：抜く部分 -->
    </g>
  </mask>
  <rect width="24" height="24" fill="currentColor" mask="url(#g_example)"/>
</svg>
```

> インライン展開時に mask の id が衝突するため、インスタンスごとに一意化すること。

## 5. Figma Variables 命名

```
badge/{tier}/{state}/{token}

tier   : N | R | SR | UR
state  : earned | locked
token  : tile-bg | tile-border | glyph | chip-bg | chip-fg | label | lock-icon
```

`lock-icon` は `locked` のみ、`glyph` は `earned` のみ有効。

コンポーネントのプロパティ構成：

| プロパティ | 値 |
|---|---|
| `tier` | N / R / SR / UR |
| `state` | earned / locked |
| `glyph` | 19グリフコンポーネントへのインスタンススワップ |

---

## 6. 検証条件

- チップ文字のコントラスト比が全8状態で 4.5:1 以上
- 48px 表示（実機相当）で N / R / SR / UR がロック状態でも判別できる
- 48px 表示で獲得済みと未獲得が判別できる
- 19グリフが48pxで互いに判別できる。特に以下のペア
  - `footsteps` / `stairs`
  - `deepen` / `broaden`
  - `overlap-1` / `overlap-2`
  - `ridge-flat` / `ridge-peak`
  - `season-spring` / `season-autumn`
- 色を無彩色化してもレア度が判別できる（チップ表記が機能しているか）

## 7. 未確定・調整余地

| 項目 | 内容 |
|---|---|
| N獲得グリフの濃度 | `#2A2F37` が強すぎる場合 `#3D434C` へ後退 |
| 細部の多いグリフ | `season-cycle` / `triad` / `deepen` は72pxで情報量が増えるため、個別に1段縮小する余地あり |
| 獲得済みと未獲得の差 | 淡色どうしのため差が小さい。不足時は獲得済みの枠線を 1px → 2px |
| 節目カテゴリのラベル | 「節目の証 / はじまりや季節に関するバッジ」は仮。正式文言に差し替え要 |
| 獲得演出・NEW表示 | 未設計。体感への効きが大きいため別途要件化が必要 |
